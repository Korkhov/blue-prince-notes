# Буквы по клеткам плана (пары картин)
В клетке плана висят две картины; слова на них отличаются одной буквой, и эта лишняя буква — буква клетки. Сетка 9 рядов × 5 столбцов. Картины привязаны к **клетке** (ряд.столбец), а не к комнате.

Фото: [photos/](photos/) (имя файла: `ряд.столбец-слово`).
