# Буквы по клеткам плана (пары картин)
В клетке плана висят две картины; слова на них отличаются одной буквой, и эта лишняя буква — буква клетки. Сетка 9 рядов × 5 столбцов. Картины привязаны к **клетке** (ряд.столбец), а не к комнате.

Фото: [photos/](photos/) (имя файла: `ряд.столбец-слово`).

## Найденные пары
| Клетка | Пара | Буква | Где |
|---|---|---|---|
| 1.1 | DESSERT / DESERT (флан на тарелке / пустынные скалы) | S | Storeroom |
| 1.2 | PRAY / PRY (молитвенно сложенные руки / рука с ломом-фомкой) | A | Hallway |
| 1.3 | FACE / ACE (рука с дамой бубен / рука с тузом пик) | F | Entrance Hall |

| 2.1 | PLANE / PLAN (биплан в облаках / свёрнутые чертежи-планы) | E | Guest Bedroom |
| 2.2 | STAIRS / STARS (винтовая лестница / четыре звезды) | I | Parlor |
