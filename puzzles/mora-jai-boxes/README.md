# Шкатулки Мора Джай
Цель: нужный цвет во всех 4 углах, затем нажать угловые символы. Символ угла = царство = цвет (пятиугольник = Fenn Aries = красный; гора = Arch Aries = жёлтый).

| Цвет | Действие |
|---|---|
| Серый | ничего |
| Белый | себя и соседей (крест) переключает белый↔серый |
| Чёрный | сдвиг ряда вправо |
| Красный | везде: белые→чёрные, чёрные→красные |
| Жёлтый | меняется с верхним |
| Фиолетовый | меняется с нижним |
| Зелёный | меняется с противоположным через центр |
| Розовый | вращает 8 соседей по часовой |
| Оранжевый | становится цветом большинства соседей (крест) |
| Синий | повторяет действие цвета в центре |
