# West Path: решения

Часть внешних владений The Grounds ([вверх](../solutions.md)). Открывается из [Garage](../../garage/solutions.md) (питание через utility box).

- Помост (мостик) через речку.
- За ним вход во внешнюю комнату (какую именно, надо уточнить, фото пока нет).
- Садовник в [журнале](../../apple-orchard/docs/gardeners-logbook/ru.md) упоминает, что раз в неделю подметает «западную тропу» (west path).
