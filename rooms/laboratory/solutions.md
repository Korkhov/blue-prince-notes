# Laboratory: решения

## Таблица Менделеева с номерами ✅
В пустой таблице пронумерованы 12 клеток. Подставляем элементы с обычной таблицы по номерам:

| № | Клетка | Элемент |
|---|---|---|
| 1 | актиноид, 6-й в ряду | **Pu** |
| 2 | 3-й период, группа 16 | **S** |
| 3 | 1-й период, группа 1 | **H** |
| 4 | актиноид, 2-й | **Th** |
| 5 | 6-й период, группа 7 | **Re** |
| 6 | лантаноид, 7-й | **Eu** |
| 7 | актиноид, 3-й | **Pa** |
| 8 | 2-й период, группа 17 | **F** |
| 9 | 5-й период, группа 16 | **Te** |
| 10 | 6-й период, группа 18 | **Rn** |
| 11 | 5-й период, группа 17 | **I** |
| 12 | 2-й период, группа 18 | **Ne** |

Pu·S·H·Th·Re·Eu·Pa·F·Te·Rn·I·Ne → **PUSH THREE UP AFTER NINE** («нажми / подними три вверх после девяти»).

Применяется к панели с рычагами 1–10 (см. ниже). Стикер со стрелкой влево рядом с таблицей — тоже часть подсказки?

## Машина с рычагами ✅
- Требует питания из **Boiler Room** ([табличка](docs/boiler-power-sign/ru.md), [питание](../../puzzles/boiler-power.md)).
- Панель: 10 рычагов (два ряда по пять, номера 1–10), шкала слева, лампа и две решётки внизу ([фото](photos/lever-panel.jpg)).
- Подсказка «PUSH THREE UP AFTER NINE»: после подачи питания нажать **рычаг 9, затем рычаг 3** (рычаги ставятся вверх).
- Результат: открылась **закрытая дверь снаружи** (металлическая дверь в [Private Drive](../the-grounds/private-drive/solutions.md)), за ней проход в [Blackbridge Grotto](../blackbridge-grotto/solutions.md).
- Электронная почта открывается **только через Office**; красная табличка «почта только через Security» лжёт ([табличка](docs/email-security-terminal-sign/ru.md)).
