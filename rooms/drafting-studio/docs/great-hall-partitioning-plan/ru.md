# Great Hall: план перегородок (Partitioning Plan)
Drafting Studio. Титульный лист: «Great Hall [План перегородок] на **пятницу, 27 ноября**». На фоне видна макетная модель зала с перегородками.

## Заметка
- Дата 27 ноября, пятница: по [календарю](../november-calendar/ru.md) день 1 = 7 ноября, значит 27 ноября = день 21 (выведено из календаря).
- Содержимое листов с планом не снято. Ср. [Great Hall](../../../great-hall/solutions.md) (запертые двери, рычаги).
