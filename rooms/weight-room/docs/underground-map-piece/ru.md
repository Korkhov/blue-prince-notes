# Кусок подземной карты (Weight Room)
Weight Room, после разбитой стены. Часть карты, видны: **1** (комната с фонарём и стрелкой вверх), **4**, **6** (стрелка влево) рядом с **Catacombs**, **8** (круглая комната с зубцами), **9** (стрелка вверх). Справа рукописная надпись обрывается: «the eighth … to …».

Остальные части карты: [фрагмент в Catacombs](../../../catacombs/docs/underground-map-fragment/ru.md), [фрагмент 2](../../../abandoned-mine/docs/underground-map-fragment-2/ru.md), [полная карта](../../../abandoned-mine/reservoir/docs/underground-map/ru.md).
