# Inner Sanctum 1: решено
Первая дверь Inner Sanctum открыта (каким ключом, не записано). Внутри **механическая загадка по [Realm & Rune](../../library/books/realm-and-rune/ru.md)**: нужно собрать печать королевства (по принципу такой же головоломки на столе в [Abandoned Mine](../../abandoned-mine/solutions.md)). Королевство здесь **Orinda Aries**.

Подсказка к решению: комната со свечами в [Tomb](../../tomb/solutions.md). Ядро Orinda Aries: вытянутая фигура с выступами (см. [королевства](../../../puzzles/realms/README.md)).

## Решение ✅ (вид на фото)
[Фото решённой печати](photos/orinda-sigil-mechanism-solved.jpg): в центре **ядро Orinda** (вытянутая фигура с выступами); **3 луча** (два диагональных вверху и один вниз), на каждом **поперечные засечки**; вокруг **5 мотков**; по кругу **кайма из точек двух размеров**.

Разбор по книге (догадка):
- 3 луча = **поезда** (рельсовый транспорт); засечки на лучах = **туман**;
- кайма из точек разной величины = **чёрная** (знамя чёрное);
- мотки по форме похожи на **Metropolitan** (город-государство).

[Фото пола](photos/floor-sigil.jpg): на полу комнаты та же печать, подсвеченная синим: вытянутая плита в центре, **3 луча с засечками** (вверх, влево-вниз, вправо-вниз), **5 мотков** вокруг; по бокам розовые канделябры.

## Награда
