# Room 8: решено
Ключ от Room 8 даёт [Gallery](../gallery/solutions.md). Восемь животных надо поставить в 8 корзин-грехов ([таблички](docs/animal-plaques/ru.md)).

| Животное | Корзина |
|---|---|
| Пингвин | GLUTTONY |
| Лев | ENVY |
| Лебедь | LUST |
| Кролик | AVARICE |
| Слон | WRATH |
| Медведь | SLOTH |
| Обезьяна | HUBRIS |
| Собака | MUNDANITY |

Награда: **2 Allowance Token** и **Trophy 8**.
- Собака ставится в корзину **MUNDANITY** ([таблички](docs/animal-plaques/ru.md)).
