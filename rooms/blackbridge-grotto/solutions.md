# Blackbridge Grotto: решения
Внешняя комната. Проход открыт рычагами **9 → 3** в [Laboratory](../laboratory/solutions.md) через металлическую дверь в [Private Drive](../the-grounds/private-drive/solutions.md) (дверь подтверждена пользователем).

- Здесь **сервер сети Blackbridge** (по логам: «небольшая пещера у восточной подъездной дороги»).
- **Загадка с микрочипами:** на постаменте с тремя гнёздами на постаменте с тремя гнёздами один [микрочип](../../items/microchip/ru.md) стоял, двух не хватало (решена, см. ниже).
- Загадка с микрочипами решена по подсказкам из книги [A New Clue](../library/books/a-new-clue/ru.md):
  - **Первый чип** лежал в вазе в [Entrance Hall](../entrance-hall/solutions.md); вазу нужно разбить. Указывала на это страница книги, где мужчина сидит на полу в виде нашего поместья, рядом ваза и молоток.
  - **Второй чип** выкопан возле моста на [West Path](../the-grounds/west-path/solutions.md). Указывала подсказка **Corner Cases**: в записках из Patio, Nook, Office и Pantry по одному слову выделено курсивом, вместе получается «**Buried besides west bridge**».
  - Награда за три вставленных чипа: секретный план этажа **Throne Room** ([планы](../../puzzles/secret-floorplans.md)). Предположение пользователя: в этой комнате может быть один из ключей Inner Sanctum.
- **Терминал**, подключён: [User Database](docs/user-database/ru.md) и [Admin Logs](docs/admin-logs/ru.md) (ключ LeeB). В логах: история сети, заговор LeeB/ProvC/HounU 1987 года.
