# Blackbridge admin logs (key MoorR)
01-20-86 MoorR — The last cables have finally been laid and the office terminal has been connected to the central network. Given the ever-changing nature of the rooms on the estate, we chose to install the server outside of the house to maintain connection stability at all times. A small cavern off of the eastern drive was selected for the server site.
01-26-86 MoorR — All remaining computer terminals on the estate are now connected to the network mainframe and we will now begin testing remote access capabilities between them. I've also asked the Baron to come up with a name for the Network.
01-30-86 MoorR — After some deliberation, our network has been named BLACKBRIDGE, a somewhat ominous name for the project given the legend from which the term derives, though very fitting considering we chose an actual cave to house the mainframe. I only hope that our servers do not suffer that same fate that befell those in the story!
07-01-86 MoorR — Regular maintenance Report – Fixed a connection error between the office and security terminal. We have also added electronic mail capabilities to each terminal that can be accessed via the network.
02-10-87 MoorR — Recording capabilities of all cameras on the estate have been disabled. Additionally, the existing video playback functionality on the Security Terminal has also been removed.
