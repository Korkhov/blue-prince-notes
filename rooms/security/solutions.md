# Security: решения

## Правило цветных записок ✅
- **Синие** = правда.
- Это про **записки (memos) на цветном фоне** (не про цвет чернил).
- **Красные** (красный фон) = ложь, **если не написаны от руки** (рукописные красные — правда).
- **Зелёные** могут быть как правдой, так и ложью.
- Ср. Darkroom: «…een memos found in Hartley's room are always false».
- Примеры: машинописная красная карточка «SAFE CODE 9083» — ложь (код Office 0303). Красная табличка в Laboratory «почта только через Security» напечатана → по правилу **ложь**.

- [Заметка с мониторами «DELETE IT!!»](docs/monitors-delete-it-sketch/ru.md); такая же заметка есть в [Safehouse](../abandoned-mine/safehouse/docs/monitors-delete-it-sketch/ru.md).

## Пароль терминала ✅ (прочитан через лупу)
- **SWANSONG** ✅ — зачёркнут на [объявлении для персонала](docs/staff-notice-terminals/ru.md), читается через лупу.
- **Электронная почта открывается только с терминала в Office**. Красная напечатанная табличка «почта только через Security» — ложь, как и положено по правилу.
- Мелкий шрифт под «RED MEMOS = LIES»: **UNLESS WRITTEN BY HAND** ([записка](docs/blue-red-memos-note/ru.md)).
- Clock Tower найден: [загадка с часами](../clock-tower/docs/clock-puzzle-notes/ru.md) — проект барона с красными и синими memos ([почта 1986](docs/terminal-emails-1986-87/ru.md)).
