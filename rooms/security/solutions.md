# Security: решения

## Правило цветных записок ✅
- **Синие** = правда.
- **Красные** = ложь, **если не написаны от руки** (рукописные красные — правда).
- Ср. Darkroom: «…een (Green?) memos found in Hartley's room are always false».
- Примеры: машинописная красная карточка «SAFE CODE 9083» — ложь (подтверждено, код Office 0303). Красная табличка в Laboratory «почта только через Security» напечатана → по правилу **ложь**. Записка Бэббидж Кристофу в Garage — красная, но рукописная → правда.

## Пароль терминала ✅ (прочитан через лупу)
- **SWANSONG** — зачёркнут на [объявлении для персонала](docs/staff-notice-terminals/ru.md), читается через лупу.
- Терминалы: Security и Laboratory (почта, по табличке, только через Security).
