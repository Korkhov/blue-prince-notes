# Места выбора комнат (Drafting Locations)
Карточка в Conservatory: где можно выбирать (драфтить) особые комнаты.

**Только Западное крыло**
- Garage
- West Wing Hall
- Her Ladyship's Chamber (из дверей, выходящих на юг)

**Только Восточное крыло**
- East Wing Hall
- Master Bedroom

**Другие особые случаи**
- Conservatory (выбирается только в углу)
- Bookshop (выбирается только из Library)
