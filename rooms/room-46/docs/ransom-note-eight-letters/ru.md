# Записка из вырезанных букв: «У нас ваши письма»
Room 46. Записка в стиле шантажа, собрана из вырезок разных шрифтов и цветов.

«Эта секретная комната не так безопасна, как ты думал. **У нас есть ваши письма.** 8 писем, 8 выплат, **100 золота**. Инструкции последуют.»

## Заметка
- Часть букв крупнее или выделена цветом/шрифтом; возможно, из них что-то складывается. **Не расшифровано** (в en.md крупные буквы выделены заглавными по фото, это моё чтение).
- «8 писем»: ср. [красные письма](../../../../documents/red-letters/README.md) (если их 8) и «8 realms in 8 months».
- Вырезанные из бумаги буквы на столе в Greenhouse (за разбитой стеной), скорее всего, связаны с этой запиской ([фото](../../../greenhouse/photos/cut-out-letters.jpg); предположение пользователя).
