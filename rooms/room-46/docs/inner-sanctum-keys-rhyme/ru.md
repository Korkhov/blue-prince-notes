# Стишок о восьми ключах (двери Inner Sanctum)
Room 46. Лист с рисунком: восемь дверей по четыре с каждой стороны полумесяца. Это записка о том, где искать ключи к **8 дверям из [Inner Sanctum](../../../the-underpass/inner-sanctum.md)**.

1. Первый ключ найден **здесь, на самом дальнем ранге**.
2. Второй **заперт в хранилище банка**.
3. Третий **высоко, среди всех часов**.
4. Четвёртый **внизу, под всеми доками**.
5. Пятый **держит король на троне**.
6. Шестой **на станции, оставлен кем-то из «твоих»**.
7. Седьмой **«мажорный», если драфтить его довольно поздно**.
8. Последний ключ **ждёт за последней из восьми дверей**.

## Где лежат ключи
Ключи одинаковые: любой ключ подходит к любой двери.

Соотнесение строк стишка с местами (вывод по описаниям; места названы пользователем).
| № | Где | Статус |
|---|---|---|
| 1 | Room 46 (здесь) | **забран** |
| 2 | Vault, сейф | лежит, не забран |
| 3 | [Clock Tower](../../../clock-tower/docs/clock-puzzle-notes/ru.md) (загадка с часами), **Sanctum Key** | **забран** |
| 4 | дно [Reservoir](../../../abandoned-mine/reservoir/solutions.md), если опустить воду до **0** через [Pump Room](../../../pump-room/solutions.md) | лежит |
| 5 | «король на троне»: место неизвестно, вероятно комната Throne Room (предположение пользователя) | не найден |
| 6 | [Safehouse](../../../abandoned-mine/safehouse/solutions.md) (станция), **Sanctum Key** | **забран** |
| 7 | [Music Room](../../../music-room/open-questions.md), если вытянуть её на Rank 9 | лежит |
| 8 | Mechanarium, когда открыты все 8 дверей | лежит |
