# Стишок о восьми ключах (двери Inner Sanctum)
Room 46. Лист с рисунком: восемь дверей по четыре с каждой стороны полумесяца. По словам пользователя, это записка о том, где искать ключи к **8 дверям из [Inner Sanctum](../../../the-underpass/inner-sanctum.md)**.

1. Первый ключ найден **здесь, на самом дальнем ранге**.
2. Второй **заперт в хранилище банка**.
3. Третий **высоко, среди всех часов**.
4. Четвёртый **внизу, под всеми доками**.
5. Пятый **держит король на троне**.
6. Шестой **на станции, оставлен кем-то из «твоих»**.
7. Седьмой **«мажорный», если драфтить его довольно поздно**.
8. Последний ключ **ждёт за последней из восьми дверей**.

## Статус ключей (со слов пользователя)
| № | Где | Статус |
|---|---|---|
| 1 | Room 46 (здесь) | найден, **не забран** |
| 2 | в сейфе | найден, **не забран** |
| 3 | в Clocktower | **забран** |
| 4 | в Safehouse | **забран** |
| 5-8 | неизвестно | не найдены |

## Заметка
- Соотнесение строк стишка с комнатами (сейф/банк, Clocktower, Safehouse) сделано пользователем; какой именно сейф и где ключ 1, в записи не уточнено.
- Строки 5-8 не расшифрованы.
