# Черновик пар слов
Лист в Study: кто-то подбирал пары слов, отличающихся одной буквой (как на парах картин). Прочтение приблизительное.

- craft / raft, draft / raft, smile / mile, vial / viral — перечёркнуты (большая диагональная черта)
- coat / cat, cold / old — зачёркнуты
- sturdy / STUDY — зачёркнуты (слово STUDY = название комнаты, где найден лист)
- acre / **face · ace** / lace — **обведено «face · ace»**: выбранная пара (буква **F**, клетка 1.3, [Entrance Hall](../../../../puzzles/picture-letters/README.md))
- beard / bard

## Заметка
- Эта пара FACE/ACE стоит в первой клетке сообщения на [доске](../letters-chalkboard/ru.md).
