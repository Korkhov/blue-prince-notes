# Utility Closet — решения
- Включить автомат GARAGE → откроются ворота гаража → West Gate → можно драфтить Shelter.
- V.A.C. indicators (6 шт.): зелёная → синяя (нажать); синяя рядом с красной → фиолетовая; 5 фиолетовых включают шестую; белый появляется только когда все 6 фиолетовые. Порядок из почты барона в Office: [off] [blue] [green] [white] [red] [purple]. См. [docs/fusebox-vac-indicators](docs/fusebox-vac-indicators/ru.md), [office/terminal-mail-1993](../office/docs/terminal-mail-1993/ru.md). В игре ещё не применено.
