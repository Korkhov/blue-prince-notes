# Электрощиток
Предупреждение DANGER: переключение может отключить функции комнат.
- KEYCARD ENTRY SYSTEM — система дверей с ключ-картой (вкл/выкл).
- V.A.C. INDICATORS — 6 индикаторов.
- Автоматы: GYMNASIUM, DARK ROOM, GARAGE, четвёртая табличка зачёркнута.

Питание Garage нужно, чтобы открыть ворота гаража → West Gate → Shelter.
