# Workshop: решено
- Ноты решены (место: Campsite, секретный план Conservatory), см. [solutions](../../puzzles/sheet-music/solutions.md).
- Все **8 устройств** Workshop собраны, получен [Trophy of Invention](docs/trophy-of-invention/ru.md).
- Рецепты Workshop:
  - [Magnifying Glass](../../items/magnifying-glass/ru.md) + [Metal Detector](../../items/metal-detector/ru.md) = [Burning Glass](../../items/burning-glass/ru.md);
  - [Metal Detector](../../items/metal-detector/ru.md) + [Shovel](../../items/shovel/ru.md) = **Detector Shovel** ([рецепт](docs/recipe-detector-shovel/ru.md)): больше шанс найти монеты и ключи, при раскопках намного больше.
  - [Coin Purse](../../items/coin-purse/ru.md) + [Lucky Rabbit's Foot](../../items/lucky-rabbits-foot/ru.md) = **Lucky Purse** ([рецепт](docs/recipe-lucky-purse/ru.md)): удваивает все найденные монеты.
  - [Compass](../../items/compass/ru.md) + [Shovel](../../items/shovel/ru.md): = **Dowsing Rod** ([рецепт](docs/recipe-dowsing-rod/ru.md)): при выборе комнат указывает на комнаты, где сегодня может быть больше предметов, чем обычно; инструкция была в [записке](docs/workshop-idea-compass-shovel/ru.md).
  - [Lock Pick Kit](../../items/lock-pick-kit/ru.md) + [Metal Detector](../../items/metal-detector/ru.md): = **Pick Sound Amplifier** ([рецепт](docs/recipe-pick-sound-amplifier/ru.md)): больше шанс вскрыть замки с высокой чувствительностью; инструкция была в [записке](docs/workshop-idea-lock-pick-metal-detector/ru.md).
  - [Sledge Hammer](../../items/sledge-hammer/ru.md) + [Battery Pack](../../items/battery-pack/ru.md) + [Broken Lever](../../items/broken-lever/ru.md) = **Power Hammer** ([рецепт](docs/recipe-power-hammer/ru.md)): разбивает стены.
  - [Shovel](../../items/shovel/ru.md) + рычаг + батарея = **Jack Hammer** ([рецепт](docs/recipe-jack-hammer/ru.md)): эффективнее лопаты при раскопках, копает глубже и находит лучшие предметы.
