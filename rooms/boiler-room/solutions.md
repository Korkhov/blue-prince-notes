# Boiler Room: решения

- **Красный блок** (высокий красный бак/щиток с трубой у основания и тёмным отверстием внизу), рядом синие коробки с трубами. Может **питать одну из трёх соседних комнат** (со слов пользователя). Нужен для комнат с машинами, как [Laboratory](../laboratory/open-questions.md): см. [питание от Boiler Room](../../puzzles/boiler-power.md).
