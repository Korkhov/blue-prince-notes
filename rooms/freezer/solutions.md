# Freezer
- Комната открывается, когда в поместье есть [Furnace](../furnace/solutions.md): температура постепенно растёт, и когда она превышает **16 градусов**, комната открывается.
- Внутри лежит [записка Денни Ревейна](docs/denny-note-servers-freezer/ru.md) (про серверы в морозильнике, админ-ключ **RevaD**).
- Есть ещё **морозильная камера, которая не размораживается**. Чтобы её разморозить, нужно либо [Burning Glass](../../items/burning-glass/ru.md), либо **факел (torch) из Armory**.
- В морозильной камере (после разморозки) лежит [письмо Герберта Саймону](docs/herbert-letter-freezer/ru.md) в конверте «разморозить только в случае моей смерти»: восемь красных конвертов спрятаны в поместье, ключ — послание из 44 символов среди картин; комбинации сейфов нигде не записаны. На последнем листе бланк послания из 44 чёрточек.
- Шахматная фигура: белая пешка ([таблица](../../puzzles/chess/README.md)).
