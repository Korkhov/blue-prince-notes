Signs on the eight clock cases. Blue signs are typed; red signs are typed except the last one, which is handwritten.

1. *(blue)* EACH OF THESE CLOCKS SHOULD BE SET TO A DIFFERENT TIME.
2. *(blue)* FIVE OF THESE CLOCKS SHOULD BE SET TO A TIME ENDING "ON THE HOUR".
3. *(red)* SET THIS CLOCK TO A TIME CONTAINING ALL DIFFERENT NUMBERS
4. *(blue)* THIS CLOCK'S NEIGHBORS SHOULD BOTH BE SET TO A TIME CONTAINING A 7.
5. *(red)* THIS CLOCK SHOULD NOT BE SET 'ON THE HOUR' (ENDING IN :00)
6. *(blue)* NONE OF THESE CLOCKS SHOULD BE SET TO TIMES THAT CONTAIN THE NUMBER 1, 2, 3 OR 4
7. *(blue)* THIS CLOCK SHOULD BE SET TO A TIME THAT CONTAINS THE SAME THREE NUMBERS OF ANOTHER CLOCK HERE BUT IN REVERSE ORDER.
8. *(red, handwritten)* The clocks are positioned so that their times will go up in ascending order.
