# «Realm & Rune: Sigils of the Past and Present» (проф. Р. Уиллард, 1905), целая копия
Library. Целый экземпляр той же книги, что порванная копия в [The Precipice](../../../the-precipice/docs/realm-sigils-book/ru.md) (там оторваны названия и часть текста; **здесь они есть**). Fenn Aries, Robert Bird & Sons, 1905. В формуляре: **29 нояб. 1993, Simon P. Jones** (от руки). В [Bookshop](../../../bookshop/solutions.md) такая книга куплена.

## Суть
**Печати королевств (Realm Sigils)**: круглые знаки на королевских артефактах, зданиях и старых документах. Каждая из **4 частей** рассказывает о королевстве.

### 1. Ядро (Core): название королевства
Фигура в центре, у каждого королевства своя. Сначала нужно определить ядро.

| Ядро | Королевство |
|---|---|
| вытянутая фигура с выступами | **Orinda Aries** |
| пятиугольник | **Fenn Aries** |
| песочные часы | **Eraja** |
| «галочка» / сердце | **Corarica** |
| пики-«корона» | **Arch Aries** |

### 2. Лучи (Rays)
**Число лучей: транспорт**

| Лучей | Транспорт |
|---|---|
| 8 | корабли, морские пути, порты (как роза ветров) |
| 4, крест «X» | дороги, улицы, кареты (перекрёсток) |
| 4, «галоп» (два горизонтальных и два вниз) | верховая езда, тропы |
| 3 | поезда, рельсовый транспорт |
| 5 | воздухоплавание, дирижабли, шары («над горизонтом») |
| 2, горизонтальные | верблюды, вьючные мулы, пустынные тропы (ровная местность) |
| 5 коротких, не доходят до каймы | езда на черепахах |

**Вид луча: погода**

| Луч | Погода |
|---|---|
| прямая чёрная линия | обычная погода и температура |
| несколько поперечных засечек с одной стороны | **ТУМАН** (foggy) |
| волнистая | **ЖАРА** |
| три вертикальные линии | **ДОЖДЬ** |
| молния | **ГРОЗЫ** |
| с падающими кружками | **СНЕГ** |
| изогнутая | **ВЕТЕР** |

### 3. Мотки (Motes): тип общества
| Значок | Тип |
|---|---|
| звёздочка | **Tribal**: первобытное, охотники и собиратели |
| круг с овалом | **Agricultural**: земледельческое |
| W | **Martial**: воинственное, многолетние войны |
| «лист с загнутым углом» | **Metropolitan**: город-государство |
| три чёрточки | **Academic**: знания, школы, университеты, библиотеки |
| квадрат с точкой | **Industrial**: инженерия, производство, изобретения |
| круг со значками | **Spiritual**: почитание природы, животных, высших сил |
| «клякса» | **Poetic**: искусство, письмо, музыка, язык |

### 4. Кайма (Border): цвет знамени
8 видов каймы = 8 цветов, всегда совпадают с цветами знамени и страны:

| Цвет | Узор каймы |
|---|---|
| чёрный | точки разного размера |
| красный | волнистые «языки пламени» |
| фиолетовый | сегменты/чёрточки |
| розовый | двойная ломаная линия |
| зелёный | косая штриховка |
| жёлтый | зигзаг |
| оранжевый | треугольнички |
| белый | мелкие кружки |

### Пример: Fenn Aries («Великое королевство»)
Печать: пятиугольник, 4 луча-«крест» с засечками на концах, 8 мотков «W», красная кайма. **Транспорт: дороги/кареты. Погода: туман. Общество: воинственное. Знамя: красное.**
