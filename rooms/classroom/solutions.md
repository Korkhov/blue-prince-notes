# Classroom: решено
Classroom «растёт»: каждый следующий раз номер класса увеличивается (Grade 1, 2, …). Документы помечены номером класса.
- **Grade 1, Color Worksheet:** правильные ответы: флаг с «короной» (Arch Aries, горы) жёлтый, бананы жёлтые, пожарный гидрант красный, флаг с «галочкой» (Corarica, сердце) оранжевый, тыква оранжевая, пруд с утками синий, ящерица зелёная, брокколи зелёная, «маркер» (скорее свёрток blueprint) синий, виноград фиолетовый, тележка красная, флаг с «песочными часами» (Eraja) фиолетовый. Сверено с оценками учеников (2/12, 9/12, 10/12): совпадает. ([листы](docs/grade-1-color-worksheets/ru.md), [плакат](docs/grade-1-colors-poster/ru.md))
- **Grade 2, Mathematics:** цвет цифры задаёт действие (синий +, жёлтый −, розовый ×, фиолетовый ÷), считать слева направо. Правильные ответы: 7, 13, 4, 1, 4, 12 и 10, 4, 2, 21, 18, 15. Сверено с оценками четырёх учеников (10/12, 9/12, 5/12, 9/12): совпадает. ([доска](docs/grade-2-mathematics-board/ru.md), [листы](docs/grade-2-math-worksheets/ru.md))
- **Grade 3, Science:** слова составляются из символов элементов. Water = W+At+Er; Ice = I+Ce; Steam = S+Te+Am. Сверено с оценками (Касандра 2/3, Джейкоб 1/3): совпадает. ([доска](docs/grade-3-science-board/ru.md), [листы](docs/grade-3-science-worksheets/ru.md), [таблица](docs/grade-3-periodic-table/ru.md))
- **Grade 4, Geography:** на листах надо сопоставить 7 областей карты и ядра печатей королевств. Расстановка выведена по оценкам: галочка — западная большая, полукруг — тёмная вверху в центре, вытянутая — светлый остров внизу в центре, горы — верхняя правая, пятиугольник — тёмная справа, ромб — чёрная в середине, песочные часы — нижняя правая. Имена для полукруга и ромба неизвестны. ([листы](docs/grade-4-geography-worksheets/ru.md), [доска](docs/grade-4-geography-board/ru.md), [Ettsphere](docs/grade-4-map-ettsphere/ru.md), [Orrsphere](docs/grade-4-map-orrsphere/ru.md))
- **Grade 5, Art:** задание «нарисуй две вещи, названия которых отличаются одной буквой». ([листы](docs/grade-5-art-prompt-worksheets/ru.md), [мольберты](docs/grade-5-art-easel-drawings/ru.md), [доски](docs/grade-5-art-boards/ru.md))
- **Grade 6, History:** тест по войне Пятой эры, четыре проверенные работы, слайды и плакат «History is penned by the Victors». Правильные ответы выведены по оценкам (3, 4, 4, 4 из 6): Teskin, Oris, two, 22 years, Eraja, Black Flag. ([тест](docs/grade-6-history-worksheets/ru.md), [слайды](docs/grade-6-history-slides/ru.md), [плакат](docs/grade-6-history-poster/ru.md))
- **Grade 7, Algebra:** доска с выражениями и три проверенные работы «Advanced Functions» (Sandra 7/12, Branson 8/12, Zack Craft 9/12). Правильные ответы выведены по оценкам: левый столбец 9, 4, 4, 36, 16, 100; правый 61, 19, 52, 22, 20, 40. ([доска](docs/grade-7-algebra-board/ru.md), [листы](docs/grade-7-algebra-worksheets/ru.md))
- **Grade 8, Erajan (иностранный язык):** доска «learn Erajan», словарь и таблица приставок/суффиксов (aj/ja первый/последний, ma/am малый/большой, ov/vo к/прочь, nev/ven новый-начало/старый-конец, el/le я буду/не буду; lor, hew, trei, yait, lune, dau, nai, arei; в раннем эраджанском не было глаголов) и три проверенные работы по переводу шести фраз. Правильные ответы выведены по оценкам: Ajlor Ulteach Nevlor, Hewam Ovett, Elswim Nevdau, Readle Nai, Treivenven, Manevtrei. ([доска](docs/grade-8-erajan-board/ru.md), [словарь](docs/grade-8-erajan-vocabulary/ru.md), [приставки и суффиксы](docs/grade-8-erajan-affixes/ru.md), [листы](docs/grade-8-erajan-worksheets/ru.md))
