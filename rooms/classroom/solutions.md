# Classroom — решения
- Лист математики — обучение правилам дартса (цвет цифры = действие). Скрытого сообщения нет.
- Проверенные листы подтверждают: действия выполняются **слева направо** (613 с розовыми: (6+1)×3 = 21, (6−1)×3 = 15).
- Листы раскраски: сердце = оранжевый, песочные часы = фиолетовый (см. [docs/color-worksheets](docs/color-worksheets/ru.md)).
