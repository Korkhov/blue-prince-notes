Листы «раскрась предметы»: флаг с **горой**, банан, гидрант, флаг с **сердцем**, тыква, пруд, ящерица, брокколи, мелок, виноград, тележка, флаг с **песочными часами**. Учитель: «Каждый цвет используется ровно дважды».
Ученики: Фредди (9/12), Бени (10/12), Калеб (2/12 — всё красным; ср. Калеб Мэннинг из RLCF?).

**Вывод** (у Фредди 3 ошибки, у Бени 2, каждый цвет дважды):
| Предмет | Цвет |
|---|---|
| Флаг с горой | **жёлтый** |
| Флаг с сердцем | **оранжевый** |
| Флаг с песочными часами | **фиолетовый** |
| Банан / тыква / пруд / брокколи / виноград | жёлтый / оранжевый / синий / зелёный / фиолетовый |
| Гидрант, тележка | красный |
| Ящерица | зелёная |
| Мелок | синий |

*Заметка: цвета символов царств совпадают со шкатулками Мора Джай (гора = Arch Aries = жёлтый — уже известно). Новое: **сердце = оранжевый, песочные часы = фиолетовый**. Выведено логически, в игре не проверено.*
