# Grade 3: доска «SCIENCE is FUN»
Classroom, **3-й класс**. Доска «Наука — это ВЕСЕЛЬЕ»: слово **FUN** составлено из плиток химических элементов: **F** (9, Fluorine, фтор), **U** (92, Uranium, уран), **N** (7, Nitrogen, азот). Подсказка к [листам](../grade-3-science-worksheets/ru.md): слова складываются из символов элементов.
