# Grade 2: доска «MATHEMATICS»
Classroom, **2-й класс**. Доска «Математика. Всё начинает складываться!» (игра слов: *add up*). Четыре знака, у каждого свой цвет:

| Цвет | Знак | Действие |
|---|---|---|
| голубой/синий | + | addition (сложение) |
| жёлтый | − | subtraction (вычитание) |
| розовый | × | multiplication (умножение) |
| фиолетовый | ÷ | division (деление) |

Ключ к [листам с примерами](../grade-2-math-worksheets/ru.md): цвет цифры подсказывает знак.
