# Зелёная записка: «всегда правда»
Treasure Trove. Зелёная записка (memo) на витрине.

**ЗЕЛЁНЫЕ ЗАПИСКИ, КОТОРЫЕ ТЫ НАЙДЁШЬ В ЭТОЙ КОМНАТЕ, ВСЕГДА БУДУТ ПРАВДОЙ.**

## Заметка
- Значит, в Treasure Trove все зелёные записки (в отличие от других комнат, где зелёные бывают и правдой, и ложью) говорят правду.
