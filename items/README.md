# Предметы
Предметы инвентаря: по папке на предмет (`items/<предмет>/`: фото, `en.md`, `ru.md`). В ru.md указывать, зачем нужен; где найден — если известно (не обязательно).

- [Broken Lever](broken-lever/): сломанный рычаг
- [Coupon Book](coupon-book/): скидка 1 монета на каждой покупке
- [Dynamite](dynamite/): динамит из Trading Post
- [Allowance Token](allowance-token/): +2 монеты к содержанию
- [Wind-Up Key](wind-up-key/): заводной ключ, деталь игры в Parlor
- [Shovel](shovel/): лопата для копания
- [Battery Pack](battery-pack/): батарейный блок, питание для устройств из Workshop
- [Magnifying Glass](magnifying-glass/): лупа, рассматривать документы ближе
- [Sledge Hammer](sledge-hammer/): кувалда, разбивает навесные замки на сундуках
- [Lock Pick Kit](lock-pick-kit/): набор отмычек, иногда открывает запертые двери
- [Compass](compass/): компас, чаще планы комнат с выходом на север
- [Lucky Rabbit's Foot](lucky-rabbits-foot/): кроличья лапка, больше шанс найти предметы
- [Deposit Box Key](deposit-box-key-304/): ключ, открывает ячейку 304
- [Microchip](microchip/): микрочип с данными, подключается к устройству (Blackbridge Grotto)
- [Burning Glass](burning-glass/): зажигательное стекло (лупа + металлодетектор в Workshop), зажигает особые свечи и фитили
- [Sleep Mask](sleep-mask/): маска для сна, +5 шагов при первом входе в каждую спальню
- [Watering Can](watering-can/): лейка, 1 самоцвет за каплю при первом входе в каждую зелёную комнату (3 капли)
- [Coin Purse](coin-purse/): кошелёк, +1 монета за каждые 3 собранные
- [Metal Detector](metal-detector/): металлоискатель, больше шанс найти ключи и монеты
- [Running Shoes](running-shoes/): кроссовки, меньше шагов теряется на длинных переходах по поместью и территории
- [Silver Key](silver-key/): ключ, дверь им ведёт в комнату со множеством дверей
- [Car Keys](car-keys/): запасные ключи от машины; машина должна быть в Garage
- [Salt Shaker](salt-shaker/): солонка, дополнительные шаги при еде
- [Keycard](keycard/): карта-пропуск, открывает электронные двери безопасности
- [Basement Key](basement-key/): ключ от подвала, найден в Antechamber
- [Sanctum Key](sanctum-key/): ключ к одной из дверей Inner Sanctum, награда за часы в Clock Tower
