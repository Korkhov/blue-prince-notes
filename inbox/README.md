# Inbox — как фотографировать

Сюда загружать фото с телефона: **Add file → Upload files**. Можно сколько угодно за раз.
В описании коммита (или в чате) можно написать комнату — например, `Library`.

## Что снимать — всё
- **Каждый документ целиком**, все страницы по порядку: письма, записки, газеты, листы, открытки, журналы.
- **Книги** — обложку, титульный лист, **все развороты** и **карточку выдачи** (даты и имена тоже бывают подсказкой).
- **Терминалы** — каждый экран, каждое письмо и пункт меню.
- **Картины, портреты, фото, карты, схемы, витражи, таблички** — и общий вид, и крупно.
- **Надписи на предметах**: бюсты, двери, сейфы, ящики, часы, плитки, мебель.
- **Мелкий текст через лупу**, если есть.
- **Головоломки** (шкатулки, рычаги, щитки) — исходное состояние до нажатий.

## Как снимать
- **Если на экране видна подпись комнаты** (внизу справа, «Library · Rank 2») — пусть попадёт в кадр; тогда комнату не нужно писать отдельно.
- Ровно, без бликов; текст должен читаться.
- Многостраничное — подряд, без других фото между страницами.
- Дубли не страшны: при разборе повторы удаляются автоматически.
