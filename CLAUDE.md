# Правила ведения репозитория

Репозиторий — заметки игрока по Blue Prince (ПК). Пользователь пишет по-русски, игра на английском.

## Куда класть
- Документ из известной комнаты: `rooms/<room-kebab>/docs/<doc-kebab>/`
  - фото: `01.jpg`, `02.jpg` … в порядке чтения (сжимать до ~1600px, JPEG q≈82)
  - `en.md` — дословная транскрипция оригинала
  - `ru.md` — перевод + короткая заметка, если важно для загадок/сюжета
- Книги библиотеки: `rooms/library/books/<book-kebab>/` (то же: фото + en.md + ru.md)
- Комната неизвестна: `documents/<doc-kebab>/`
- Серии записок, разбросанные по разным местам: `documents/<серия>/<запись>/` + `README.md` со списком (пример: `documents/foreman-logs/`)
- Документы одной загадки из разных комнат (например, ноты): `puzzles/<загадка>/`, в ru.md указать, где найдены
- По каждой комнате: `solutions.md` (решённое) и `open-questions.md` (чекбоксы `- [ ]`). Решили — отметить `[x]` и перенести в solutions.
- Загадки на несколько комнат: `puzzles/`
- Сюжет/персонажи: `story/timeline.md`
- Обновлять «Что ещё не решено» в `README.md`.

## Inbox
- `inbox/` — сюда пользователь загружает фото. При разборе: отсеять дубли (перцептивный хэш против уже имеющихся фото), разложить новые по правилам выше, удалить из `inbox/` (README оставить), отчитаться: дубли / новые / куда легли / какие комнаты неизвестны.

## Стиль
- Подсказки без спойлеров, если пользователь не просил ответ; но в solutions.md ответы пишутся полностью.
- Помечать, если ответ взят из гайда и не проверен в игре.
- Коммиты на русском, коротко.
