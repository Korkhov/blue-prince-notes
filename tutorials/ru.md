Обучающие карточки игры:
01 Заведите блокнот для заметок.
02 Драфт: при клике на дверь тянешь 3 чертежа, выбираешь один; некоторые предметы/комнаты дают перевытянуть.
03 Разброс предметов: особые комнаты разбрасывают предметы по дому; с Conference Room они собираются там.
04 House Directory (кнопка RB) — информация о комнатах.
05 Кувалда сбивает навесные замки с сундуков (стены — только Power Hammer).
